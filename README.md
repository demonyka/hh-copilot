# hh·copilot

Десктоп-приложение (macOS / Windows) в айдентике **hh.ru**: вход в аккаунт hh.ru
через встроенный браузер, аналитика по резюме, чаты, авто-отклики с ИИ, решение
тестов, авто-ответы работодателям и уведомления о собеседованиях в Telegram.

Всё работает **локально, в самом приложении** — один бинарник, никаких серверов
и подписок. ИИ подключается ваш собственный (любой OpenAI-совместимый).

---

## Возможности

- **Вход в hh.ru** через встроенный браузер (cookies остаются только у вас).
- **Аналитика резюме**: KPI (отклики / приглашения / собеседования / отказы за
  день/неделю/месяц/всё время), круговая диаграмма исходов, конверсия, график
  откликов по дням, 7-дневная статистика hh.ru (показы/просмотры/приглашения).
- **Чаты** — встроенный мессенджер hh (`chatik.hh.ru`), все переписки и ответы
  в реальном времени.
- **Автоотклики** (движок на Dart, порт логики Go-референса):
  - поиск вакансий и отправка откликов с сопроводительным письмом от ИИ;
  - **решение тестов** ИИ, если у вакансии есть тест;
  - **авто-ответы в чатах** работодателям (в т.ч. выбор из кнопок-вариантов),
    очистка отказных чатов;
  - фоновый цикл (повторять по интервалу), тестовый режим (ничего реально не
    отправляет).
- **Собеседования** — «умное» определение приглашений по смыслу сообщения
  работодателя (звонок, встреча, просьба написать/прислать контакты, оффер), не
  по ненадёжной метке hh. Детект идёт тем же проходом по чатам, что и авто-ответы.
- **Уведомления в Telegram** о найденных собеседованиях.
- **Автообновления** — проверка новых версий на GitHub Releases.

---

## Как это работает

hh.ru не имеет открытого API для этого сценария и защищён анти-ботом (DataDome),
поэтому приложение работает с сайтом **от имени пользователя**, через настоящий
браузерный движок:

1. **Сессия.** Встроенный браузер (`flutter_inappwebview`) авторизуется на hh.ru.
   Cookies и XSRF-токен остаются только на устройстве.
2. **Данные.** Запросы к hh.ru идут через `fetch` **внутри браузерного
   контекста** (метод `AppState.hhRequest`) — они несут cookies пользователя и
   проходят анти-бот. Ответы (HTML со встроенным JSON) разбираются в Dart.
3. **Чат-API** (`chatik.hh.ru`) кросс-доменный для hh.ru, поэтому запросы к нему
   идут через веб-вью раздела «Чаты» (для него это same-origin).
4. **ИИ** (письма, ответы в чатах, решение тестов, классификация собеседований) —
   ваш OpenAI-совместимый сервер, прямой HTTP-запрос (`AiClient`).
5. **Telegram** — прямой запрос к Bot API.

Движок откликов и детект собеседований написаны на Dart и крутятся в приложении —
отдельного сервера/процесса нет.

## Запуск (разработка)

Нужен установленный [Flutter](https://docs.flutter.dev/get-started/install).

```sh
flutter pub get
flutter run -d macos      # или: flutter run -d windows
flutter test              # юнит-тесты парсеров и расчётов
```

## Сборка релиза (один артефакт)

```sh
flutter build macos --release
#  → build/macos/Build/Products/Release/hh_copilot.app  (universal: Intel + Apple Silicon)

flutter build windows --release
#  → build/windows/x64/runner/Release/  (hh_copilot.exe + dll + data)
```

### Платформенные требования

- **macOS.** В entitlements включён `com.apple.security.network.client` (для
  запросов к ИИ, GitHub, Telegram). Сборка подписана ad-hoc — на **вашей** машине
  запускается сразу; для раздачи другим нужен Developer ID + нотаризация (иначе
  получатель делает правый клик → «Открыть» или снимает карантин:
  `xattr -dr com.apple.quarantine hh_copilot.app`).
- **Windows.** Встроенный браузер использует **WebView2 Runtime** (на Windows 11
  предустановлен; на Windows 10 может понадобиться
  [Evergreen WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)).

## Автообновления

Приложение при старте (и по кнопке в «Настройках») проверяет последний релиз в
GitHub Releases репозитория `demonyka/hh-copilot`, сравнивает версию с текущей
(из `pubspec.yaml`) и, если есть новее, показывает **красную полосу сверху** с
кнопками «Что нового» и «Обновить». «Обновить» открывает страницу релиза или
прямую ссылку на артефакт под вашу ОС (`.dmg`/`.zip` для macOS, `.exe`/`.zip` для
Windows). Установка — вручную (скачать и заменить).

**Чтобы выпустить обновление:** поднимите `version:` в `pubspec.yaml`, соберите
релиз, создайте GitHub Release с тегом вида `v1.1.0` и приложите артефакты.

## Как пользоваться

1. Запустите приложение и войдите в hh.ru (как соискатель).
2. **Аналитика** и **Чаты** доступны сразу.
3. **Модель ИИ** (в «Автооткликах»): укажите адрес OpenAI-совместимого сервера,
   модель и ключ (OpenAI, DeepSeek, локальный Ollama/LM Studio). Кнопка
   «Проверить ИИ».
4. **Автоотклики**: выберите резюме и фильтры, включите «Откликаться на вакансии»
   и/или «Отвечать в чатах», нажмите «Старт». **Сначала прогоните в тестовом
   режиме** (включён по умолчанию) и проверьте тексты в журнале.
5. **Telegram** (в «Настройках»): токен бота (от @BotFather) и chat id (узнать у
   @userinfobot), кнопка «Отправить тест».
6. **Собеседования**: приглашения находятся, пока работает «Ответы в чатах», и
   уходят в Telegram. Уведомления не зависят от тестового режима — можно получать
   их, не отвечая реально (запустите «Ответы в чатах» в тестовом режиме).

## Структура

```
lib/
  main.dart                          — корневой каркас + провайдеры, баннер обновлений
  theme/hh_theme.dart                — палитра и типографика в стиле hh.ru
  models/                            — модели профиля, аналитики, настроек бота, лидов
  services/
    hh_profile_parser.dart           — разбор /applicant/resumes
    hh_analytics_parser.dart         — разбор статистики и откликов
    hh_resume.dart, json_scan.dart   — общие помощники разбора
    ai_client.dart                   — OpenAI-совместимый клиент (письма, тесты, детект)
    autoresponder.dart               — движок откликов (поиск → письмо/тест → отклик)
    chat_responder.dart              — авто-ответы в чатах + отдача сообщений детектору
    interview_detector.dart          — эвристика приглашений
    telegram_client.dart             — Bot API
    update_service.dart              — проверка GitHub Releases
  state/
    app_state.dart                   — сессия, навигация, выбор резюме, hh-запросы
    autoresponder_controller.dart    — два процесса бота (отклики / ответы)
    interviews_controller.dart       — список приглашений + Telegram
    settings_controller.dart         — настройки Telegram
    update_controller.dart           — состояние обновлений
  screens/                           — вход, каркас, аналитика, чаты, автоотклики,
                                       собеседования, настройки
  widgets/                           — логотип, сайдбар, дропдаун резюме, поля бота,
                                       баннер обновлений
test/                                — тесты парсеров и расчётов аналитики
```

## Оговорки

- Автоматизация действий на hh.ru — на ваш риск и под вашу ответственность
  (условия использования hh.ru). По умолчанию включён **тестовый режим**; давайте
  разумные лимиты и паузы.
- Авто-ответы и очистка отказных чатов затрагивают реальные переписки — сначала
  проверяйте в тестовом режиме, что и как бот делает (журнал).
- Все данные (hh.ru-сессия, ключ ИИ, токен Telegram) хранятся локально на
  устройстве.
